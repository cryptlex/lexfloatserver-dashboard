# lexfloatserver-dashboard

LexFloatServer dashboard: a React SPA built with Vite, TanStack Router, TanStack Query and `@cryptlex/web-components`.

## Development

Requires Node 24 and pnpm.

```sh
pnpm install
pnpm dev        # http://localhost:3000, /api is proxied to LexFloatServer on http://localhost:8090
pnpm build      # production build into dist/, then type-check
pnpm check      # biome lint + format
```

## Notes

- Routes are file based under `src/routes/`. `src/routeTree.gen.ts` is generated by the router plugin, so don't edit it by hand.
- LexFloatServer serves the build at `/` and returns `index.html` for unknown paths, so routes use normal URLs. A route must not end in a dotted segment like `/clients/10.0.4.18` (see `SERVER.md` §2.2).
- LexFloatServer has no OpenAPI spec, so API calls go through the small `apiFetch` wrapper in `src/lib/api.ts` instead of a generated client.
- All user-facing text lives in `messages/en.json` and is compiled by Paraglide's Vite plugin into `src/paraglide` (generated, not committed). Use it as `m['productsPage.action.activate']()` from `@/paraglide/messages.js`. Keys follow the same `<subject>.<kind>` conventions as web-portals-react (`messages/README.md` there). Run `pnpm dev` or `pnpm build` once before type-checking so `src/paraglide` exists.
